trigger: model_decision
description: Protocol for adding new external libraries or dependencies.
---

When a solution requires adding a new library to the project, do not pick one arbitrarily.
1. Identify the need.
2. If multiple popular options exist (e.g., Glide vs Coil, Retrofit vs Ktor), list them with a brief comparison.
3. Ask me to choose the preferred library.
4. Once confirmed, proceed with the implementation in Gradle.
